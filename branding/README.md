# Branding Workspace

This folder is the home for Ugly Manling brand references and visual source material.

Use it as the single place to collect:
1. inspiration,
2. logos,
3. typography references,
4. color references,
5. product imagery,
6. moodboards,
7. exports used by design or engineering.

## Folder Structure
1. `references/`
2. `moodboards/`
3. `logos/`
4. `product-images/`
5. `social-direction/`
6. `exports/`
7. `notes/`

## Where To Upload Things
### `references/`
Drop screenshots, saved images, brand references, UI references, packaging inspiration, and anything that helps define the visual direction.

Recommended examples:
1. competitor screenshots,
2. editorial references,
3. apparel references,
4. masculine grooming brand references,
5. healthcare or wellness references worth reacting against.

### `moodboards/`
Use this for grouped visual directions.

Examples:
1. one folder or board for bold editorial direction,
2. one for rugged product branding,
3. one for research or trust-oriented visual language,
4. one for app UI inspiration.

### `logos/`
Store logo explorations and final marks here.

Recommended structure:
1. rough concepts,
2. selected directions,
3. final exports.

### `product-images/`
Store product photography, mockups, reference images, packaging concepts, apparel imagery, hats, accessories, and related product visuals here.

### `social-direction/`
Store references for Instagram, TikTok, creator partnerships, thumbnails, ad directions, meme patterns, and any visual style that should inform acquisition content.

### `exports/`
Use this for ready-to-use assets that may be consumed by the app or shared with collaborators.

Examples:
1. compressed PNGs,
2. web-ready JPGs,
3. hero images,
4. profile avatars,
5. temporary assets for prototyping.

### `notes/`
Store written context that explains the direction behind the imagery.

Examples:
1. what feels on-brand,
2. what feels off-brand,
3. visual themes to pursue,
4. themes to avoid,
5. early naming of design directions.

## Suggested Workflow
1. Drop raw inspiration into `references/`.
2. Curate stronger directions into `moodboards/`.
3. Write short rationale files in `notes/`.
4. Promote approved assets into `logos/` or `exports/`.

## Naming Guidance
Use descriptive names so files are easy to scan later.

Good examples:
1. `barber-branding-reference-01.jpg`
2. `editorial-black-red-type-direction.png`
3. `ugly-manling-logo-concept-a.svg`
4. `research-ui-reference-clean-grid.jpg`

## Important Rule
Do not scatter brand assets across the repo.

Put all visual references here first so the brand system has one source of truth.
