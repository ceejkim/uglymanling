# Content Generation Workflow

## Purpose

Use this workflow when generating product, community, recommendation, or research-adjacent content.

## Steps

1. Start with `docs/vision/vision.md` and `branding/BRAND_SYSTEM.md`.
2. Confirm the content supports a clearer barber decision, stronger trust, or better booking confidence.
3. Keep claims evidence-backed and decision-oriented.
4. Avoid shame, hype, corporate tone, or generic wellness language.
5. If a claim touches treatment, health, or outcomes, route it through the appropriate trust review before publishing.
