# Feature Build Workflow

## Purpose

Use this workflow for net-new product features.

## Steps

1. Read `docs/vision/vision.md`, `docs/plan/plan.md`, and `agents/agent.md`.
2. Confirm the feature strengthens the barber recommendation platform.
3. Define the smallest end-to-end slice before building abstractions.
4. Prepare a handoff packet using `agents/workflows/handoff-template.md` if multiple roles are involved.
5. Build with trust, proof, booking flow, and moderation implications in mind.
6. Validate the user path, analytics needs, and regression risk before closing the work.
