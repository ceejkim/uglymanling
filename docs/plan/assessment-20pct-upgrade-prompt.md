# Assessment 20% Upgrade Prompt

Use this prompt to evaluate and improve the Ugly Manling self-assessment without rebuilding it from scratch.

## Prompt

You are a three-person product review team:

1. an epidemiologist focused on useful, privacy-respecting signal collection,
2. a UI researcher focused on completion, comprehension, emotional safety, and mobile usability,
3. a growth adoption strategist focused on trusted conversion, repeat use, and community contribution.

Evaluate the existing Ugly Manling hair-loss self-assessment and results experience. The primary goal is to give men dealing with balding hair genuinely useful personal information about where they are, while also building high-quality aggregate health insights that may reveal correlations worth studying.

Constraints:

1. Do not design a new product from scratch.
2. Aim for a targeted 20% improvement in question quality, reporting value, user trust, and adoption.
3. Preserve anonymous-first capture and avoid shame, fear, fake urgency, or medical overclaiming.
4. Prefer plain-language survey signals over clinical diagnosis claims.
5. Return value to the participant before asking for money or deeper contribution.
6. Treat community insights like a cautious 23andMe-style report: personal result, matched cohort, confidence level, aggregate patterns, and clear limitations.

Evaluate:

1. Question quality: missing high-signal variables, ambiguous wording, adaptive logic, data type quality, answer option quality, and longitudinal usefulness.
2. UI quality: first-screen promise, progress clarity, cognitive load, mobile ergonomics, trust language, and places where feedback or monetization interrupts the flow.
3. Growth adoption: completion drivers, shareable value, membership fit, consult/barber routing, opt-in trust, and measurable events.
4. Reporting: what the individual user should care about, what the community should care about, what should be free, what should be premium, and what claims need caveats.

Output:

1. five highest-leverage fixes,
2. questions to add, remove, or reword,
3. UI refinements,
4. reporting modules for the user,
5. reporting modules for the community,
6. instrumentation or data-quality notes,
7. a concise implementation plan that keeps the change to roughly 20%.

## Recommendations Applied

1. Reframed the entry experience so the user gets a personal baseline first and contributes to aggregate insights second.
2. Fixed identifier and scoring mismatches that weakened consent handling, confidence-impact reporting, progression logic, budget handling, and longitudinal readiness.
3. Added four compact, high-signal questions:
   - natural hair texture,
   - current shedding amount,
   - clinician-named likely hair-loss type,
   - main treatment path for outcome tracking.
4. Collapsed per-question feedback behind a small disclosure so the survey stays focused while preserving research-quality feedback.
5. Expanded results into a personal baseline report, matched cohort report, and research roadmap with confidence caveats.
