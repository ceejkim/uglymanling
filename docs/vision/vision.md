# Ugly Manling Vision

## Purpose

This document defines the product vision, current scope, and operating constraints for Ugly Manling.

Agents should use this document as a decision filter before proposing or building features.

## Executive Summary

Ugly Manling becomes the most trusted platform for men navigating hair loss by helping them take real-world action with confidence.

The first and most important job is simple:

**Recommend the best barbers for balding men.**

Everything else is secondary until that decision is solved extremely well.

## Vision Statement

Ugly Manling will become the default platform for men dealing with hair loss.

It earns that position by first becoming:

**The most trusted place to find a barber for balding men.**

Over time, the platform expands into a broader system for navigating the full hair-loss journey, but trust starts with one high-confidence recommendation.

## Mission: Current Phase

Help balding men confidently choose the right barber by:

- identifying barbers who understand hair loss
- providing proof through real results
- reducing uncertainty before the appointment

## Strategic Focus: Phase 1

Ugly Manling is currently a:

**Barber recommendation platform for balding men**

The primary output of the platform is:

**A clear, trustworthy recommendation of which barber a user should go to.**

Everything in the product must support that outcome.

## Core User Problem

Men experiencing hair loss face a broken experience when choosing a barber:

- they do not know which barbers are actually skilled with balding hair
- they cannot reliably see real outcomes before committing
- style advice is inconsistent or not tailored to hair loss
- they make decisions with low confidence

Ugly Manling replaces this with:

- clarity
- proof
- confident action

## Core Value Proposition

**"We tell you exactly which barber you should go to and show you why."**

This is delivered through:

- curated barber recommendations
- real haircut outcomes and photos
- structured reviews
- style context tied to hair-loss scenarios

## Core Product Output

The platform must produce:

- ranked barber recommendations
- clear reasoning for each recommendation
- visual proof, ideally before-and-after or strong outcome photos
- location-based relevance

If a user leaves without a confident next step, the product has failed.

## Core User Loop

Every feature should reinforce this loop:

1. User discovers Ugly Manling.
2. User searches for barbers.
3. User receives a recommendation.
4. User visits the barber.
5. User uploads a haircut result and review.
6. Platform improves recommendations.
7. New users enter through shared results and proof.

This loop drives:

- trust
- growth
- data accumulation

## Product Scope: Phase 1

### 1. Barber Recommendation Engine

- location-based search
- filtering for balding expertise
- ranking logic

Early ranking can be simple. Later ranking should become data-driven.

### 2. Barber Profiles

Each barber profile should include:

- real client results, especially balding cases
- styles performed
- short description of strengths
- location
- booking link

### 3. User Contributions

Users should be able to:

- upload haircut results
- leave reviews
- optionally tag hair-loss stage
- optionally tag style outcome

### 4. Proof System

This is a critical product principle:

- photos over text
- outcomes over claims
- real users over marketing

## Product Constraints

The following are explicitly out of scope for now:

- telehealth
- treatment recommendations
- product marketplace
- subscriptions
- complex AI personalization

These may matter later, but they are distractions in Phase 1.

## Differentiation

Ugly Manling is not:

- Yelp for barbers
- Instagram for haircuts
- generic grooming advice

Ugly Manling is:

**A decision engine for balding men to choose the right barber with confidence.**

Key differentiators:

- narrow focus on hair loss
- proof-driven recommendations
- structured data over random content
- strong, distinct brand voice

## Brand Voice

The product should feel:

- bold
- funny
- direct
- slightly aggressive
- highly useful

Voice guidelines:

- humor should reduce anxiety
- never shame the user
- never make fake claims
- avoid corporate tone

## Success Criteria: Phase 1

Ugly Manling is succeeding if:

- users receive clear barber recommendations
- users take action and book a barber
- users return to upload results
- content quality compounds over time
- organic growth increases through shared proof

## Data Strategy

The platform should collect:

- haircut outcomes
- barber performance signals
- style success patterns

This data later powers:

- recommendation ranking
- personalization
- monetization

## Near-Term Expansion

Only after the barber recommendation system is working well, expand into:

### Style Bank

Curated styles for balding men, mapped to:

- hair-loss stage
- face shape
- density patterns

This should stay tied directly to real barber outcomes.

### Style Guidance

Simple support for questions like:

- what should I ask my barber for
- what styles fit my level of hair loss

These features should increase:

- conversion
- confidence
- repeat engagement

## Long-Term Roadmap

### Phase 2: Style and Confidence

- advanced style recommendations
- progress tracking
- confidence coaching

### Phase 3: Treatment Decisions

- minoxidil guidance
- finasteride guidance
- telehealth integration

### Phase 4: High-Intent Services

- transplant referrals
- dermatology access

### Phase 5: Commerce

- curated products
- grooming kits
- subscriptions

## Product Standard

Before building anything, ask:

1. Does this improve barber recommendations?
2. Does this increase user confidence?
3. Does this strengthen the core user loop?
4. Is this necessary right now?

If the answer is no, do not build it.

## Operating Principle

Start with one decision.

Win that decision completely.

Then expand outward.

## Agent Guidance

When making product, design, growth, or engineering decisions:

- prioritize trust over feature count
- prioritize proof over marketing language
- prioritize confidence over content volume
- prioritize the barber recommendation flow over adjacent opportunities

If a proposal does not clearly strengthen the core recommendation experience for balding men, it should be deprioritized.
