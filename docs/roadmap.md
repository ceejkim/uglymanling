# Ugly Manling Roadmap

This roadmap summarizes the active build sequence from [plan.md](/Users/charleskimbell/Rekkoe/docs/plan/plan.md).

## Near-Term Phases

1. Stabilize the foundation: auth sync, durable barber data, event tracking, and safe admin workflows.
2. Launch the recommendation core: searchable directory, strong barber profiles, booking CTAs, and core moderation.
3. Build the proof loop: reviews, haircut-result submissions, post-booking follow-up, and proof ranking.
4. Build the partner layer: claim flows, request-to-be-listed, partner verification, and basic partner analytics.
5. Deepen the community layer: richer discussions, contributor identity, and localized trust signals.

## Roadmap Rule

If a proposed initiative does not improve barber recommendations, booking confidence, or post-appointment proof, it should not outrank the phases above.
